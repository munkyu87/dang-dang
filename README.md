# 땅땅! (dang-dang)

가칭 AI 땅땅!. 로그인 없는 반응형 웹으로, 일상 다툼을 재미용 판결로 바꾸는 개인 프로젝트다. 법적 효력은 없다.

## 문서

개발에 쓰는 기준은 아래 순서다.

1. 기능, API, DB, 보안: [AI_Judge_v2_1_FINAL_Cursor_Spec.md](docs/AI_Judge_v2_1_FINAL_Cursor_Spec.md)
2. 화면 흐름과 시안: [AI_Judge_v2_1_FINAL_Visual_Spec.pdf](docs/AI_Judge_v2_1_FINAL_Visual_Spec.pdf)
3. 시각 방향: [DDANG_01_Design_Concepts.pdf](docs/DDANG_01_Design_Concepts.pdf). 기본 UI는 01 네오 브루탈리즘이다. 이 문서는 색·컴포넌트는 02 디자인 가이드, 브랜드는 03 브랜드 가이드가 우선이라고 적혀 있다. 그 두 파일은 아직 저장소에 없다.
4. 처음 기획: [AI 판사 기획안 - Grok Bot.pdf](<docs/AI 판사 기획안 - Grok Bot.pdf>). 최종 명세가 우선한다.

v2.1 명세 04절의 네이비·아이보리·골드 팔레트는 초기 제안이다. 디자인 콘셉트는 그 팔레트를 네오 브루탈리즘 토큰으로 바꾼다.
